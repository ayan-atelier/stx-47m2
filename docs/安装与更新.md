# 安装与更新

1. 在 SillyTavern 打开“扩展 → 下载扩展 → 安装扩展”。
2. 输入 GitHub 仓库地址，安装后刷新酒馆。
3. 刷新酒馆后，打开“扩展设置 → 砚台 · 小说生产 → 打开小说生产”。电脑端也可以从输入栏三横菜单打开；手机上优先使用扩展设置入口。
4. 在“API 与文风”填写纠偏 API、模型、Key、题材规则和作者声音，并分别保存。
5. 保持自动纠偏开启，正常生成一条主回复。扩展会把原版保存在消息元数据中，再生成去 AI 味版。
6. 在“当前版本”查看原版、去 AI 味版或对照，按需复制、重试，或采用某个版本。
7. 导入 `presets/` 中的小说生产模式预设，作为主 API 预设使用。

扩展更新由酒馆的扩展管理负责。预设 JSON 不会被扩展自动覆盖；预设有新版本时，在仓库中下载新的 JSON 后重新导入，旧聊天中的原稿与修订稿不会丢失。
