# 砚台 · 小说生产

SillyTavern 个人小说生产扩展：主 API 负责生成小说正文，第二 API 负责保真去模板化，并保存原稿与修订稿供对照。

## 一键安装

在 SillyTavern 的“扩展 → 下载扩展 → 安装扩展”中输入本仓库的 GitHub 地址。酒馆会从仓库根目录读取 `manifest.json`。

安装后刷新酒馆，最稳妥的入口是“扩展设置 → 砚台 · 小说生产 → 打开小说生产”；电脑端也可以从输入栏三横菜单打开“小说生产”。第一次打开后，在“API 与文风”填写第二 API 地址、模型和 API Key，再保存项目题材规则与作者声音。

## 更新

酒馆扩展设置中开启扩展更新提醒。仓库发布新版本后，在扩展管理里检查并更新即可。当前版本的小说模式预设位于 `presets/`，需要时重新导入对应 JSON。

## 工作方式

- 主回复原文永久保存在当前消息的 `extra.yantai_novel` 中。
- 修订稿由第二 API 异步生成，失败不会覆盖原稿。
- 扩展面板支持原版、去 AI 味版、对照、复制、重试和采用版本。
- 记忆插件保持独立，不把修辞变化当成剧情事实。

## 使用步骤

1. 打开“扩展设置”，找到“砚台 · 小说生产”，点击“打开小说生产”。手机上也优先从这里进入。
2. 在“API 与文风”填写纠偏 API 地址、模型名称和 API Key，点击“保存 API 设置”。
3. 按项目填写“题材与叙事约束”和“作者声音与示例段落”，点击“保存项目文风”。
4. 保持“每次主回复完成后自动纠偏”开启，正常让主 API 生成回复。
5. 主回复完成后，扩展会保留原版并生成修订版；在“当前版本”里选择原版、去 AI 味版或对照查看，也可以复制、重试或采用其中一个版本。

## 目录

- `index.js`、`src/`、`style.css`：扩展本体
- `presets/`：小说生产模式预设
- `tests/`：核心逻辑测试
