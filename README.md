# 砚台 · 小说生产

SillyTavern 个人小说生产扩展：主 API 负责生成小说正文，第二 API 负责保真去模板化，并保存原稿与修订稿供对照。

## 一键安装

在 SillyTavern 的“扩展 → 下载扩展 → 安装扩展”中输入本仓库的 GitHub 地址。酒馆会从仓库根目录读取 `manifest.json`。

安装后刷新酒馆，在输入栏三横菜单打开“小说生产”，填写第二 API 地址、模型和 API Key，再保存项目题材规则与作者声音。

## 更新

酒馆扩展设置中开启扩展更新提醒。仓库发布新版本后，在扩展管理里检查并更新即可。当前版本的小说模式预设位于 `presets/`，需要时重新导入对应 JSON。

## 工作方式

- 主回复原文永久保存在当前消息的 `extra.yantai_novel` 中。
- 修订稿由第二 API 异步生成，失败不会覆盖原稿。
- 扩展面板支持原版、去 AI 味版、对照、复制、重试和采用版本。
- 记忆插件保持独立，不把修辞变化当成剧情事实。

## 目录

- `index.js`、`src/`、`style.css`：扩展本体
- `presets/`：小说生产模式预设
- `tests/`：核心逻辑测试
